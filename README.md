📝 Django Notes App

A peaceful space to write your thoughts

🌿 Project Description (Peaceful & Professional)

The Django Notes App is a simple and calming web application designed to help users write, manage, and organize their personal notes and thoughts in one place.
The app focuses on clarity, ease of use, and simplicity, allowing users to express ideas peacefully without distractions.

Users can:

Create new notes for thoughts or ideas

Edit notes anytime

Delete notes when no longer needed

This project demonstrates core Django CRUD operations, clean UI logic, and proper backend integration using Django’s MVC (MVT) architecture.

🧠 Features

🆕 Create Notes

✏️ Edit Existing Notes

🗑️ Delete Notes

📋 View All Notes

🎯 Simple & Clean UI

🔒 Secure with Django ORM
